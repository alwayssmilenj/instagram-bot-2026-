## ⚡ 1-Click Setup Commands

### 🐧 Linux (Ubuntu, Debian, Fedora, Arch)
```bash
# Clone and enter the repository
git clone https://github.com/alwayssmilenj/instagram-bot-2026-.git
cd instagram-bot-2026-

# Run the automated installer
./setup.sh

# Fill in your .env credentials
nano .env

# Launch the bot
./run.sh
```

---

### 🪟 Windows Subsystem for Linux (WSL)
```bash
# Inside your WSL terminal (Ubuntu/Debian)
git clone https://github.com/alwayssmilenj/instagram-bot-2026-.git
cd instagram-bot-2026-
./setup.sh
```

---

### 🪟 Native Windows (Command Prompt / PowerShell)
1. Open PowerShell or Command Prompt.
2. Clone repository:
   ```cmd
   git clone https://github.com/alwayssmilenj/instagram-bot-2026-.git
   cd instagram-bot-2026-
   ```
3. Run `setup.bat` to auto-create virtual environment and install packages.
4. Edit `.env` with your Instagram credentials.
5. Double-click `run.bat` or run:
   ```cmd
   run.bat
   ```

## 🌐 24/7 Private Hosting Methods

### 🚀 Method 1: Local Linux 24/7 Systemd Daemon (Recommended)
Host directly on your Linux machine with zero cloud fees and full uptime:
```bash
# 1-Click install 24/7 background system service
./host_locally.sh

# Bot Management Commands
./botctl.sh status      # View live CPU, RAM, & status
./botctl.sh logs        # Stream real-time logs
./botctl.sh restart     # Restart service
./botctl.sh stop        # Stop service
./botctl.sh start       # Start service
```

---

### 🐳 Method 2: Docker & Docker Compose
```bash
# Build and run detached container
docker compose up -d

# Check live logs
docker compose logs -f
```

---

### ☁️ Method 3: Cloud PaaS (Render / Railway / Koyeb)
1. Connect your private GitHub repo `alwayssmilenj/instagram-bot-2026-` to **Render** or **Railway**.
2. Add your environment variables in the Cloud Settings Dashboard:
   - `IG_USERNAME`, `IG_PASSWORD`, `OWNER_USERNAME`, `AI_MODEL`, etc.
3. Deploy automatically using the included `Dockerfile` or `render.yaml` / `Procfile`.

## 🔒 Security & Zero-Leak Guarantee

> 🛡️ **Zero Hardcoded Secrets Policy**:
> Every credential, token, and API key is 100% environment-driven.

- **Air-Tight `.gitignore`**: Blocks `.env`, `.env.*`, `session/`, auth cookies (`youtube-cookies.txt`), SQLite databases (`*.sqlite3`), PID files, and caches from being tracked or pushed.
- **Sovereign Immunity**: Prevents unauthorized users or rogue commands from banning, kicking, or muting the bot owner (`jinshi`).
- **Rate-Limiting & Memory Guards**: 2 GB memory ceiling and graduated cooldown limits to protect Instagram account safety.
